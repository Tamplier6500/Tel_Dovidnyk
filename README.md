# Телефонний довідник (PWA v1.6.5)

Автономний мобільний і десктопний телефонний довідник для роботи без інтернету.

## Деплой на GitHub Pages
1. Завантажте всі файли (`index.html`, `manifest.json`, `sw.js`, `icon.svg`) у корінь репозиторію.
2. Перейдіть у **Settings → Pages**.
3. У розділі **Build and deployment** виберіть **Deploy from a branch**, гілку `main` і папку `/ (root)`, натисніть **Save**.
4. Відкрийте посилання вигляду `https://<username>.github.io/<repo>/` на смартфоні та натисніть **Меню ⋮ → Встановити додаток**.
